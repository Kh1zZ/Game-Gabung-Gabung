# 🎮 Game Gabung-Gabung

Game web puzzle kasual berbasis grid 3x3 yang dirancang khusus untuk layar sentuh HP (mobile-friendly). 

### 🎯 Cara Bermain
Geser dan gabungkan 2 gambar dengan tingkatan yang sama untuk meningkatkannya ke level berikutnya (Level 1 s/d Level 6). Tujuan akhir permainan adalah berhasil mengumpulkan **3 buah gambar Level 6 di papan** secepat mungkin!

---

## ✨ Fitur-Fitur Utama

- **📱 Tampilan Homescreen & Mobile Touch:** Halaman awal yang bersih, tombol sentuh responsif, kontrol *drag-and-drop* presisi, serta dukungan navigasi keyboard (Arrow/WASD, Enter, Space, Escape) dan fitur **Undo** untuk membatalkan langkah.
- **🏆 Misi Tamat (Finished):** Permainan selesai dan menang saat kamu berhasil mengumpulkan 3 buah gambar Level 6 secara bersamaan di papan.
- **⏱️ Timer & Rekor Waktu:** Timer otomatis berjalan dari geseran pertama untuk mengukur kecepatan bermain dan mencatat rekor waktu tercepat (*Best Time*).
- **🔊 Audio Eskalasi Per Level:** Suara efek dari video yang semakin tinggi dan mencekik seiring tingginya level penggabungan gambar (Level 2 s/d 6).
- **🎵 Upload Suara Kemenangan Kustom:** Bebas upload lagu atau sound effect kemenangan sendiri (format `.mp3`, durasi maksimal 1 menit) yang tersimpan aman di browser (*IndexedDB*).
- **🖼️ Upload Gambar Kustom:** Fitur untuk mengganti gambar placeholder angka 1–6 dengan foto favorit sendiri langsung dari galeri HP atau file PC.
- **⚡ 100% Web Statis:** Tanpa database/backend yang rumit, super cepat, dan siap dideploy langsung ke **Vercel**, Netlify, atau GitHub Pages.
